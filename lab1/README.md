# Лабораторная работа №1
## «Алгоритмизация обработки целых чисел»

### Вариант №4

### Условие задачи

Найти все числа, при записи которых в обратном порядке получается число, квадрат которого является квадратом исходного числа, записанным в обратном порядке следования цифр.

**Формулировка в виде свойства:**  
Если число \( n \) перевернуть (получить \( rev(n) \)), то должно выполняться равенство:

\[
rev(n^2) = (rev(n))^2
\]

Нужно найти все такие числа в заданном диапазоне (например, от 1 до введённого пользователем предела).

### Требования к программе

1. Логически законченные части алгоритма оформить в виде **отдельных функций** с параметрами
2. **Глобальные переменные запрещены**
3. Программа должна содержать **не менее двух функций**
4. Проверка корректности ввода данных с выводом сообщений об ошибках

### Алгоритм решения

1. Ввод верхней границы поиска с проверкой на корректность
2. Перебор всех чисел от 1 до введённого предела
3. Для каждого числа:
   - Вычислить перевёрнутое число
   - Вычислить квадрат исходного числа и перевернуть его
   - Вычислить квадрат перевёрнутого числа
   - Сравнить результаты
4. Вывести все числа, удовлетворяющие условию

### Необходимые функции

- `reverse(int n)` — переворачивает число (например, 123 → 321)
- `check(int n)` — проверяет, выполняется ли условие для числа n
