# Лабораторная работа №2
## «Вычисление значений функции с помощью разложения в ряд»

### Вариант №30

### Задание

Вычислить значение функции \( y = \sqrt[n]{a} \) в точке по итерационной формуле:

\[
y_{i+1} = \frac{1}{n} \left( (n-1) \cdot y_i + \frac{a}{y_i^{\,n-1}} \right)
\]

**Начальное приближение:** \( y_0 = a \)

**Тип данных:** `double` (число с плавающей точкой двойной точности)

### Требования к программе

#### Программа №1 (по количеству членов ряда)

- Пользователь указывает **количество членов ряда** (итераций)
- Функция на вход получает: параметры \( a \), \( n \) и количество итераций
- Возвращает вычисленное значение \( \sqrt[n]{a} \)

#### Программа №2 (по точности)

- Пользователь указывает **точность** (например, \( \varepsilon = 10^{-9} \))
- Функция на вход получает: параметры \( a \), \( n \) и точность
- Возвращает:
  - вычисленное значение \( \sqrt[n]{a} \)
  - количество итераций, потребовавшееся для достижения заданной точности (через параметр-указатель)

#### Общие требования для обеих программ

1. Вычисление значения **также с использованием стандартной библиотеки** (`pow(a, 1.0/n)`) для сравнения
2. Оценка **области сходимости ряда** — определить, при каких \( a \) и \( n \) формула сходится
3. Оценка **погрешности вычислений** — определить количество верных цифр в результате
4. **Запрещены глобальные переменные**
5. Логически законченные части — в виде отдельных функций
6. Проверка корректности ввода с выводом сообщений об ошибках и продолжением работы
7. Корректная работа с памятью (проверка через `valgrind`)

### Алгоритм решения

**Итерационная формула (метод Герона для корня n-й степени):**

\[
y_{i+1} = \frac{1}{n} \left( (n-1) y_i + \frac{a}{y_i^{n-1}} \right)
\]

Условие остановки (для программы №2):
\[
|y_{i+1} - y_i| < \varepsilon
\]

### Необходимые функции

- `double root_n_iterations(double a, int n, int iterations)` — вычисление корня по количеству итераций
- `double root_n_precision(double a, int n, double eps, int *iterations_used)` — вычисление корня с заданной точностью, через указатель возвращает количество итераций
- `double root_n_lib(double a, int n)` — вычисление через `pow(a, 1.0/n)` для сравнения
- `int count_significant_digits(double approx, double exact)` — оценка количества верных цифр


### Область сходимости

Формула сходится для:
- \( a > 0 \) (положительные числа)
- \( n \ge 2 \) (степень корня)
- При \( a < 0 \) сходимость зависит от чётности \( n \) (для чётных \( n \) корня не существует в действительных числах)

Рекомендуемый диапазон: \( a \in (0, 10^6] \), \( n \in [2, 10] \)
