# Лабораторная работа №3
## «Динамические массивы. Работа с последовательностями данных»

### Вариант №64

### Задание

Для исходного массива целых чисел A найти такие индексы i и j, которые позволяют получить максимальную сумму элементов массива между данными индексами (включительно):

\[
\sum_{k=i}^{j} A[k]
\]

**Дополнительно:** сохранить элементы из найденного диапазона в новом массиве, удалив их из исходного.

### Тип данных

Целые числа (`int`)

### Требования к программе

#### Основная функциональность (меню)

1. **Инициализация массива** — заполнение массива в цикле
2. **Вставка нового элемента** по индексу (сдвиг вправо)
3. **Удаление элемента** по индексу (сдвиг влево)
4. **Индивидуальное задание** — поиск диапазона с максимальной суммой
5. **Вывод текущего состояния массива**

#### Правила работы с памятью

- Динамическое выделение памяти: `malloc()`, `calloc()`, `realloc()`, `free()`
- **VLA (массивы переменной длины) запрещены**
- Размер выделенной памяти всегда равен количеству элементов в массиве
- При вставке/удалении память перевыделяется через `realloc()`

#### Правила вставки и удаления

- **Вставка:** при индексе ≥ длины массива — вставка в конец
- **Удаление:** при индексе ≥ длины массива — ошибка
- После любой операции — автоматический вывод содержимого массива

#### Взаимодействие с пользователем

- Диалоговое меню (буквенный или числовой выбор)
- Завершение: выбор пункта меню или `Ctrl+D` / `Ctrl+Z` (EOF)
- Проверка корректности ввода с выводом сообщений об ошибках

#### Требования к коду

- **Запрещены глобальные переменные**
- Логические части — в отдельных функциях
- Функции обработки массивов **не должны быть диалоговыми** (все данные — параметры, результат — через возврат и коды ошибок)
- Исключения: функции инициализации и вывода
- Код разбит на `.c` и `.h` файлы
- Проверка памяти через `valgrind`


### Необходимые функции

| Функция | Описание |
|---------|----------|
| `init_array()` | Инициализация массива (ввод с клавиатуры) |
| `insert_element()` | Вставка элемента по индексу |
| `delete_element()` | Удаление элемента по индексу |
| `find_max_subarray()` | Поиск индексов максимальной суммы |
| `extract_subarray()` | Копирование диапазона в новый массив и удаление из исходного |
| `print_array()` | Вывод массива |
| `free_array()` | Освобождение памяти |
