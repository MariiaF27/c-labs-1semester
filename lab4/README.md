# Лабораторная работа №4
## «Работа со строками»

### Вариант №24

### Задание

Удалить из строки символ, встречающийся чаще всего.

### Общая постановка задачи

Из входного потока вводится произвольное количество строк произвольной длины. Каждая строка содержит одно или более слов, разделенных пробелами и/или знаками табуляции. Завершение ввода — конец файла (Ctrl+D / Ctrl+Z).

Для каждой входной строки формируется новая выходная строка, в которую помещается результат:
- Слова разделяются **только одним пробелом**
- **Нет пробелов** в начале и в конце строки
- Введённая и сформированная строки выводятся на экран в **двойных кавычках**

### Структура лабораторной

Лабораторная работа состоит из двух частей:

| Часть | Описание |
|-------|----------|
| **Лабораторная №4а** | Использование `readline()` из GNU readline + стандартные функции `<string.h>` |
| **Лабораторная №4б** | Собственная реализация всех строковых функций (`mystring.h`, `mystring.c`) |


### Требования к программе

#### Общие требования

1. Каждая строка представлена на физическом уровне **вектором** (динамический массив)
2. **VLA (массивы переменной длины) запрещены**
3. Целочисленные и строковые константы — через `#define`
4. Завершение при EOF (Ctrl+D / Ctrl+Z)
5. Логические части — в отдельных функциях
6. Код разбит на `.c` и `.h` файлы
7. **Глобальные переменные запрещены**
8. Проверка памяти через `valgrind`

#### Дополнительно для лабораторной №4б

- Ввод строк через `scanf()` со спецификаторами для строк
- **Запрещены:** `gets()`, `getchar()`, спецификаторы `%c` и `%m`
- Все библиотечные функции заменены на собственные реализации

### Необходимые функции (стандартные и их реализации)

| Функция | Назначение |
|---------|------------|
| `my_strlen()` | Вычисление длины строки |
| `my_strcpy()` | Копирование строки |
| `my_strcat()` | Конкатенация строк |
| `my_strcmp()` | Сравнение строк |
| `my_strchr()` | Поиск символа в строке |
| `my_strtok()` / аналог | Разбиение на слова |

### Алгоритм обработки строки

1. **Подсчёт частоты символов** (массив на 256 символов ASCII)
2. **Нахождение максимальной частоты**
3. **Формирование новой строки** — копируем все символы, кроме тех, частота которых = максимальной
4. **Нормализация пробелов**:
   - Удалить ведущие и trailing пробелы
   - Заменить множественные пробелы на один


### Сборка и запуск

**Для 4а:**

# Компиляция (требуется библиотека readline)
gcc main.c process.c -o lab4a -lreadline

# Запуск
./lab4a

# Проверка памяти
valgrind ./lab4a 

**Для 4b:**
# Компиляция
gcc main.c process.c mystring.c -o lab4b

# Запуск
./lab4b

# Проверка памяти
valgrind ./lab4b
