# Лабораторная работа №5
## «Массивы структур. Сортировки. Таймирование»

### Вариант №257

### Структура данных

| Поле | Тип | Описание |
|------|-----|----------|
| наименование | `char*` (строка произвольной длины) | Название организации |
| ИНН | `char[13]` (12 символов + `\0`) | Строка из 12 цифр |
| количество работников | `int` | Целочисленное значение |

### Алгоритмы сортировки

1. **Гномья сортировка** (Gnome sort)
2. **Сортировка вставками с бинарным поиском** (Insertion sort with binary search)
3. **Быстрая сортировка** `qsort()` из стандартной библиотеки (для сравнения)

### Структура лабораторной

| Часть | Задача |
|-------|--------|
| **5а** | Прототип программы №1: структуры, аргументы командной строки (`getopt`), ввод-вывод |
| **5б** | Завершение программы №1: добавление сортировок |
| **5в** | Программа №2: таймирование сортировок + анализ сложности |

## Программа №1

### Функциональность

#### 1. Ввод массива
- (а) из стандартного потока ввода (клавиатура)
- (б) из текстового файла (указание имени файла)
- (в) из бинарного файла (указание имени файла)

#### 2. Вывод массива
- (а) в стандартный поток вывода (экран)
- (б) в текстовый файл (указание имени файла)
- (в) в бинарный файл (указание имени файла)

#### 3. Сортировка массива
- (а) выбор алгоритма (Gnome / BinaryInsertion / qsort)
- (б) выбор поля для сортировки (наименование / ИНН / количество работников)
- (в) выбор направления (по возрастанию / по убыванию)


## Программа №2 

### Функциональность

- Генерация массивов случайных структур заданного размера
- Замер времени выполнения каждой сортировки
- Возможность выбора:
  1. Алгоритма сортировки
  2. Поля для сортировки
  3. Направления сортировки
  4. Количества элементов в массиве
  5. Количества генерируемых массивов (для усреднения)

## Сборка и запуск

```bash
# Компиляция программы №1
gcc -Wall -Wextra -Werror -O2 main.c org.c io.c sort.c -o lab5

# Компиляция программы №2 (таймирование)
gcc -Wall -Wextra -Werror -O2 timer.c org.c sort.c -o lab5_timer

# Запуск программы №1
./lab5 -i data.txt -o result.bin -s name -a gnome -d asc

# Запуск таймера
./lab5_timer -n 10000 -m 10 -s employees -a qsort -d desc

# Проверка памяти
valgrind ./lab5 -i data.txt
valgrind ./lab5_timer -n 1000 -m 5
