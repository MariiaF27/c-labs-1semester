# Лабораторная работа №6
## «Работа со структурами данных на основе списков»

### Вариант №27

### Задание

Осуществить **циклический сдвиг на N символов влево** в каждом слове строки.


### Общая постановка задачи

Из входного потока вводится произвольное количество строк произвольной длины. Каждая строка содержит одно или более слов, разделенных пробелами и/или знаками табуляции. Завершение ввода — конец файла (Ctrl+D / Ctrl+Z).

Для каждой входной строки формируется выходная строка путём **модификации исходной** (без создания нового списка). В полученной строке слова разделяются только одним пробелом. Исходная и полученная строки выводятся в двойных кавычках.

### Физическое представление данных

Каждая строка представлена **односвязным списком**


Каждый символ строки (включая пробелы) — отдельный узел списка.

### Требования к программе

1. Каждая строка — **список**. Элемент списка: символ + указатель на следующий
2. Выходная строка формируется **путём модификации исходного списка** (без создания нового)
3. Перестановка элементов — через **манипуляции указателями** (обосновать выбор)
4. Ввод строк — через **`getchar()`**, каждый символ сразу добавляется в список
5. **Запрещены глобальные переменные**
6. Логические части — в отдельных функциях
7. Проверка памяти через `valgrind`

### Алгоритм обработки строки

Для каждого слова в строке (последовательность символов, не являющихся пробелами):

1. Найти начало слова и его длину `len`
2. Вычислить эффективный сдвиг: `shift = N % len`
3. Если `shift == 0` — слово не меняется
4. Иначе:
   - Отсоединить первые `shift` символов слова
   - Присоединить их в конец слова
   - (Всё через манипуляции указателями, без создания новых узлов)

### Нормализация пробелов

После обработки всех слов:
- Удалить лишние пробелы (множественные пробелы заменить на один)
- Удалить пробелы в начале и конце строки

### Необходимые функции

| Функция | Описание |
|---------|----------|
| `node_create(char c)` | Создание нового узла |
| `list_append()` | Добавление символа в конец списка |
| `list_print()` | Вывод списка в кавычках |
| `list_free()` | Освобождение памяти |
| `find_word_start()` | Поиск начала следующего слова |
| `find_word_end()` | Поиск конца слова |
| `cyclic_shift_left()` | Циклический сдвиг слова (через указатели) |
| `normalize_spaces()` | Приведение пробелов к одному |
| `process_line()` | Обработка одной строки (списка) |
